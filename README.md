* ⚡ **Sub-10ms Cold Boot**: 100% offline local-first performance. No spinning database wheels.

* 📱 **Native Mobile Feel (iOS & Android)**:
  * Floating Frosted Glass Thumb Dock
  * Center Elevated `(+)` Quick Capture Capsule
  * Native Slide-Up Bottom Sheets (Zero `window.prompt()`)
  * Full PWA Support (Add to Home Screen on iOS & Android)
* 🔊 **Procedural Web Audio Synthesizer**: In-browser real-time acoustic synthesis (14ms mechanical micro-clicks, liquid drops, and 528Hz Solfeggio chords) with zero external MP3 assets.
* 👑 **The "Day Cleared" Sacred Completion Ritual**: When The Big 3 are won, the workspace transforms with a radiant golden-hour bloom and celebratory chime.
* 🗂️ **The 5 Interconnected Pillars**:
  1. **Cockpit**: Daily Focus, The Big 3, GTD Next Actions, 7-Day Rolling Habit Matrix.
  2. **P.A.R.A Hub**: Root Areas of Life (Vitality Gauges), Active Projects with Milestone Velocity & Budget Burn, Cold Archives.

  4. **Fitness & Wellness**: Concentric Activity Rings, 1-Tap Fast Macros, Workout Routines with Auto-Sync to Habits.
  5. **Knowledge Hub**: Visual Bookshelf with Reading Progress & Quote Pullouts, Project Swipe Files.

## Local Development & Preview

Serve the application using any static server:

```bash
# Python 3
python -m http.server 3333

# Or Node.js
npx serve .
```

Open `http://localhost:3333` in any desktop or mobile browser.
